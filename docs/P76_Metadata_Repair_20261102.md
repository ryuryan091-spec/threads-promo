## 범위
2026-11-02 실행41436174054의 R04/R07 오탐과 불필요한 전체 재작성을 처리한다. 사건유형표 연결, 범용 AI검수 실패 재개, 관제 상태 개편은 이번 변경 범위에 포함하지 않는다.

## 검증 설계
risk_notes의 확인된 두 안전 준수 절만 R04:industry/R07:harm_term 단어 검사에서 제외한다. 마침표 또는 줄바꿈으로 구분한 절 전체가 정확히 일치할 때만 예외다. 다른 규칙, 특히 사용자 금칙어 R03은 원문을 검사한다. 같은 note의 나머지 절과 모든 서사 필드는 계속 검사한다. AI 검수에는 수정하지 않은 전체 바이블을 전달한다. 일반적인 부정문이나 메타데이터 전체를 제외하지 않는다.

공통 규칙 결과에 @최상위필드 위치를 붙인다. 이전 위치 없는 rules 결과는 저장 초안을 재검사하여 위치를 다시 계산한 뒤 부분 수정 대상으로 사용한다.

## 초안 재사용
이전 rules 실패이고 현재 프롬프트 버전과 일치하며 저장 초안이 현재 검사를 모두 통과하면 writer를 건너뛰고 AI검수한다. 작성 시도 횟수는 증가시키지 않는다. 현재 next_job의 총3회 한도는 그대로 유지한다. API 실패 후 범용 검수 재개는 별도 후속 작업이다.
새 초안에는 model/fallback/내용hash를 함께 저장한다. 출처가 없거나 내용hash가 다르면 출처 미검증으로 처리하여 AI PASS여도 HUMAN_REQUIRED보다 낮아지지 않는다. 현재 운영의 과거 초안은 출처 메타데이터가 없어 명시승인 대상이 될 수 있다. 기존 로그만 보고 코드가 출처를 추정하지 않는다.
부분 수정 시 남겨둔 초안 필드의 출처도 확인하며, 미검증 원본에 새 모델 이름만 덮어써 신뢰하지 않는다.
