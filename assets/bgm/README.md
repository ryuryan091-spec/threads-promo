# BGM 슬롯

이 디렉터리에 **라이선스를 확보한** 배경음 파일(.mp3/.m4a/.wav/.aac/.ogg)을 넣으면
렌더링 시 자동으로 합성된다. 파일이 없으면 영상은 무음으로 남는다(기존 동작 유지).

- 파일이 여러 개면 매 실행마다 무작위로 하나가 선택된다
  (X 안티봇 원칙: 동일 패턴 반복 금지).
- 볼륨은 0.35로 낮춰 합성되며, 영상 길이에 맞춰 자동 루프/컷된다.
- 코드는 음원을 인터넷에서 자동으로 내려받지 않는다.
  YouTube 저작권 클레임을 피하기 위해 음원 확보는 반드시 수동으로 한다.
- 디렉터리 경로는 환경변수 `BGM_DIR` 로 변경할 수 있다 (기본값 `assets/bgm`).
