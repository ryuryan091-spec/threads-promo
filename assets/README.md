# assets

Threads 게시물에 사용할 이미지를 여기에 커밋합니다.
기존 파이프라인(investment_comic_tube / ICG)이 이미 생성한 컷을 재사용하십시오.
신규 이미지 생성은 과금 대상일 수 있으므로 권장하지 않습니다.

## 규격 (Threads 공식 제한)
- 형식: JPEG / PNG
- 용량: 8MB 이하
- 폭: 320px 이상 1440px 이하1
- 종횡비: 10:1 이내
- 색공간: sRGB

## 파일명
`promo_01.png`, `promo_02.png` ... 형태로 정렬 가능하게 둡니다.
선택은 `day_of_year % 파일수` 로 결정되므로 별도 순번 관리가 필요 없습니다.
