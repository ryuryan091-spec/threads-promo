# 오프닝 훅 효과음(SFX) 슬롯

훅 구간(0~3초)에 내레이션 위로 얹을 효과음을 넣는다.
파일이 없으면 효과음 없이 내레이션만 재생된다(기존 동작 유지).

## 유형별 파일명 (권장)
| 파일명 | 훅 유형 | 성격 |
|---|---|---|
| `hook_a.wav` | 충격/경고형 | 경보음, 사이렌 |
| `hook_b.wav` | 빌런 대결형 | 타격음, 충돌음 |
| `hook_c.wav` | 반전/팩트형 | 전환음, 위시(whoosh) |
| `hook_d.wav` | 긴급 속보형 | 속보 시그니처, 전자음 |

- 유형별 파일이 없으면 디렉터리 내 임의 파일 1개가 무작위로 선택된다.
- 지원 확장자: `.wav` `.mp3` `.m4a` `.aac` `.ogg`
- 길이는 1초 내외를 권장한다(훅 구간이 3초라 길면 내레이션을 덮는다).
- 볼륨은 0.7로 낮춰 합성되므로 원본은 정규화된 파일을 쓰면 된다.
- **코드가 음원을 자동으로 내려받지 않는다.** YouTube 저작권 클레임을 피하기 위해
  라이선스를 확보한 파일만 직접 배치한다.
- 경로는 환경변수 `SFX_DIR` 로 변경 가능(기본 `assets/sfx`).
