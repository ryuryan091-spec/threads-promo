# 캐릭터 레퍼런스 이미지 슬롯

여기에 히어로 **EDT**의 기준 외형 이미지(.png/.jpg/.webp)를 넣으면,
이후 모든 회차의 이미지 생성 요청에 참조 이미지로 함께 전달되어
회차 간 외형(얼굴, 털 무늬, 수트, 체인소)이 고정된다.

- 파일이 없으면 텍스트 프롬프트만으로 생성한다(기존 동작 유지).
- **비용 주의**: 참조 이미지는 입력 토큰으로 과금된다(이미지당 약 1,120토큰).
  현재 회차당 이미지 3장을 생성하므로, 레퍼런스 1장을 넣으면
  회차당 약 3,360 입력토큰이 추가된다.
- 권장: 마음에 드는 회차의 `artifacts/images/scene_1.png`(EDT 등장 컷)을
  내려받아 `edt_hero.png` 로 커밋한다.
- 여러 장 넣으면 전부 전달되므로 비용이 배로 늘어난다. 1장을 권장한다.
- 디렉터리 경로는 환경변수 `REFERENCE_DIR` 로 변경 가능(기본 `assets/reference`).
