# 브랜드 자산 (아웃트로 엔드카드)

## 배치 파일

| 파일 | 용도 | 필수 |
|---|---|---|
| `EDT_UNIVERS_Invest_01_Area.png` (또는 임의 이름) | 아웃트로 표지 이미지 | 없으면 아웃트로 생략 |
| `logo.png` | 우하단 오버레이 로고 (파일명 `logo` 고정) | 없으면 로고 없이 표지만 |

- `logo` 라는 이름은 **오버레이 전용으로 예약**되어 있다. 그 외 이미지는 전부 표지 후보다.
- 표지를 여러 장 넣으면 매 실행 무작위로 1장이 선택된다 (X 안티봇 원칙).
- 지원 확장자: `.png` `.jpg` `.jpeg` `.webp`
- 경로는 환경변수 `BRAND_DIR` 로 변경 가능(기본 `assets/brand`).

## 왜 인트로가 아니라 아웃트로인가

쇼츠는 0~3초 이탈이 노출량을 좌우한다. 앞에 공통 브랜드 화면을 두면
훅(EDT 클로즈업 + 충격 문구)이 뒤로 밀려 스와이프를 막지 못한다.
아웃트로는 이 부작용이 없으면서 시리즈 인지와 구독 유도에 기여한다.

## 로고를 PNG 로 두는 이유

이미지 생성 모델은 짧은 영문 글자('EDT')도 자주 뭉개고 회차마다 모양이 달라진다.
로고는 고정 PNG 를 ffmpeg 로 오버레이해 100% 일관성을 확보한다.
배경 투명(alpha) PNG 를 권장한다.

## 사양

- 표지: 세로 9:16 (1080x1920 권장). 다른 비율이면 자동으로 크롭된다.
- 로고: 화면 폭의 18% 크기로 축소되어 우하단 여백 60px 지점에 배치된다.
- 아웃트로 길이: 2초 (`OUTRO_DURATION_SEC`)
